# BridgeMesh

> **Сеть, в которой люди соединяют людей — без интернета, без сотовых вышек, без цензуры.**

Приложение BridgeMesh создано командой [RybinskLab](https://rybinsklab.ru) — резидентом Рыбинска, работающим в сфере информационной безопасности и серверных решений.

Идея проста: когда у людей нет связи (отключили интернет, нет сотовой сети, блокада города), телефоны всё равно могут «разговаривать» друг с другом напрямую — через **Bluetooth** и **Wi-Fi Direct**. BridgeMesh превращает каждый телефон в маленькую радиостанцию: что бы вы ни отправили, оно само найдёт путь через людей поблизости.

---

## 🔥 Почему это важно

- **Нет интернета — есть общение.** Сообщения идут через соседние устройства. Несколько человек = mesh-сеть.
- **Не нужен сервер.** Никто не хранит ваши сообщения, никто не выдаёт их по запросу спецслужб.
- **Сквозное шифрование.** Даже посредники, через которых идёт сообщение, не видят текст — только зашифрованный блоб.
- **Контакты из записной книжки.** Если вы и собеседник ввели номера телефонов — BridgeMesh покажет имя из «Контактов» Android.

## ✨ Что умеет

| Функция | Описание |
|---------|----------|
| 📡 **Mesh-сеть** | Bluetooth + Wi-Fi Direct. Сообщение само идёт через посредников. |
| 🔒 **Шифрование** | Канал между вами и собеседником шифруется (AES-256). |
| 🔁 **Хранение-и-доставка** | Сообщения хранятся у встречных людей до 7 дней и доходят, когда появляется связь. |
| 🏙 **Городские комнаты** | Включили геолокацию — попали в чат своего города (например, Рыбинск). |
| 👥 **Контакты** | Добавляйте людей по короткому коду, по QR, вручную через ID. |
| 🚨 **SOS** | Один тап — соседи увидят, что вам нужна помощь. |
| 💾 **Бэкап** | Парольная копия чатов и контактов, восстанавливается на новом устройстве. |

## 🛡 Разрешения — для чего каждое

Мы не скрываем, что запрашиваем — каждое разрешение реально нужно для работы offline-сети:

| Разрешение | Зачем |
|------------|-------|
| `INTERNET` | **НЕ запрашивается.** Принципиально. |
| `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT` / `BLUETOOTH_ADVERTISE` | Найти людей рядом и передать сообщения через BLE. |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | На Android BLE-скан требует геолокацию. Также для определения города. |
| `NEARBY_WIFI_DEVICES` | Wi-Fi Direct нужен для скоростной передачи между телефонами. |
| `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | Переключение Wi-Fi и определение типа сети. |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_CONNECTED_DEVICE` | Сеть работает, пока приложение свернуто. |
| `POST_NOTIFICATIONS` | Уведомление «вы в mesh-сети» + звук/вибро при входящем SOS. |
| `CAMERA` | Только для QR-кодов (добавление контакта). Не используется для съёмки. |
| `FLASHLIGHT` | Зарезервировано для SOS-маяка. |
| `WAKE_LOCK` | Чтобы передача не останавливалась в фоне. |
| `VIBRATE` | Тактильное подтверждение при отправке SOS. |
| `RECEIVE_BOOT_COMPLETED` | Возобновить работу после перезагрузки устройства. |

## 📖 Как работает mesh

```
Ты ──► Аня (50 м, BT) ──► Боря (30 м от Ани, Wi-Fi) ──► Вася
                       ↘
                       Дима ─► Женя
```

1. Вы отправляете сообщение адресату.
2. Телефон смотрит, кто рядом. Если адресат виден — отправляет напрямую.
3. Если нет — отправляет ближайшему соседу с пометкой «для Васи». Сосед повторяет то же самое.
4. Сообщения хранятся у промежуточных участников до **7 дней**. Если один из узлов встретил адресата — сообщение доставляется.

> Приватные сообщения шифруются общим ключом, выведенным из идентификаторов вас и собеседника. Промежуточные узлы видят только зашифрованный блоб.

## 📲 Установка

1. Скачайте `app-debug.apk` из раздела [Releases](../../releases).
2. Откройте на Android-телефоне (Android 7.0+).
3. Разрешите установку из неизвестных источников.
4. Запустите BridgeMesh и введите имя.

> Релизная версия без интернета и регистрации — открыли, начали общаться.

---

## 🛠 Сборка из исходников

```bash
# Требования: Flutter 3.47+, Android SDK 35+, JDK 21.
git clone https://github.com/gotical/bridgemesh.git
cd bridgemesh
flutter pub get
flutter build apk --debug
```

APK будет в `build/app/outputs/flutter-apk/app-debug.apk`.

### Конфигурация

Все настройки находятся в `android/app/build.gradle.kts`. Сборка работает на Termux (см. CI workflow). Установка `pointycastle: ^3.9.1` подтягивает 4.0 без `PaddedBlockCipher` — для AES используется ручной PKCS7-padding.

## 🧪 Безопасность

| Что | Как реализовано |
|-----|-----------------|
| E2E-шифрование | AES-256-CBC, ключ = `SHA-256(sorted(aliases))` |
| HMAC-подпись пакетов | HMAC-SHA256 от полезной нагрузки + nonce |
| Анти-спам визиток | Подпись HMAC + дедупликация по `packetId` |
| Бэкап | Пароль → PBKDF2-HMAC-SHA256 (20 000 итераций) → AES-CBC |
| Нет сервера | Архитектура: каждый узел = клиент + ретранслятор |

## 📁 Структура проекта

```
lib/
├── app.dart              # Точка входа, DI-граф сервисов
├── models/               # MeshPacket, Contact, RoomMessage, ...
├── services/
│   ├── identity_service  # Идентификатор узла, имя, телефон, история
│   ├── permission_service # Запрос разрешений
│   ├── routing_service   # Оркестратор mesh: сборка, доставка, store-and-forward
│   ├── transport_*.dart  # BLE / Wi-Fi Direct транспорты
│   ├── contact_service   # Мои контакты, заявки, авто-выученные
│   ├── room_service      # Городские комнаты (геочаты)
│   ├── message_store     # Хранилище сообщений и ретрансляция
│   ├── secure_chat       # AES + ручной PKCS7
│   ├── backup_service    # Бэкап/восстановление
│   ├── geo_service       # Геолокация, определение города
│   └── phonebook_service # Сверка номера с записной книжкой
└── ui/
    ├── home_screen.dart  # TabBar, статус-бар, главная
    └── widgets/          # Панели и переиспользуемые компоненты
```
