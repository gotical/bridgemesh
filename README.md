# BridgeMesh

> **Связь без интернета и сотовой связи. На случай, когда электричество есть, а интернета — нет.**

BridgeMesh от команды [RybinskLab](https://rybinsklab.ru) — простая утилита для случаев, когда пропадает интернет или сотовая связь (отключение электричества, природные катаклизмы, отдалённые районы). Приложение превращает каждый Android-телефон в радиостанцию: сообщения идут через соседние устройства через Bluetooth и Wi-Fi Direct.

Никаких серверов, аккаунтов, слежки. Приложение — просто инструмент связи на случай ЧС.

---

## 🔥 Зачем

- **Интернет пропал, электричество есть.** Свяжитесь с соседями без интернета и сотовой связи.
- **Там, где нет покрытия.** Лес, горы, малонаселённые места — телефоны соединяются напрямую.
- **Чрезвычайные ситуации.** Передайте SOS с координатами, увидите, что у соседей происходит.

---

## ✨ Что умеет

| Функция | Описание |
|---------|----------|
| 📡 **Mesh-сеть** | Bluetooth + Wi-Fi Direct. Сообщение идёт через соседние телефоны. |
| 💬 **Личная переписка** | Зашифрованные сообщения 1-на-1. Диалоги хранятся локально. |
| 🏙 **Городские чаты** | Общий чат вашего города (например, Рыбинск) — координаты определяются автоматически. |
| 🚨 **SOS** | Экстренный сигнал с местоположением для всех в эфире. |
| 🔔 **Уведомления офлайн** | Локальные push без интернета — о входящих сообщениях и SOS. |
| 👥 **Контакты** | Добавляйте людей по QR или короткому коду. |
| 🔋 **Режим экономии** | Кнопка «Отключиться» — узел остаётся посредником, но тратит в 5-10 раз меньше заряда. |
| 💾 **Бэкап** | Копия чатов и контактов на новый телефон, защищена паролем. |

## 📱 Установка

1. Скачайте `app-debug.apk` со страницы [Releases](../../releases).
2. Установите на Android 7.0 или новее.
3. Запустите BridgeMesh, введите имя.
4. Включите Bluetooth и геолокацию.
5. Ваш телефон начнёт искать соседей с BridgeMesh поблизости.

> Приложение работает только офлайн. Никакой регистрации, никаких серверов.

## 🛡 Разрешения — для чего каждое

Мы не скрываем, что запрашиваем — каждое разрешение реально нужно для работы:

| Разрешение | Зачем |
|------------|-------|
| `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT` / `BLUETOOTH_ADVERTISE` | Найти людей рядом и передавать сообщения через BLE. |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | Android требует геолокацию для BLE-сканирования + для определения города. |
| `NEARBY_WIFI_DEVICES` | Wi-Fi Direct для скоростной передачи между телефонами. |
| `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | Переключение Wi-Fi. |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_CONNECTED_DEVICE` | Сеть работает, пока приложение свернуто. |
| `POST_NOTIFICATIONS` | Локальные уведомления о входящих сообщениях и SOS. |
| `CAMERA` | Только для QR-кодов (добавление контакта). |
| `FLASHLIGHT` | Зарезервировано для SOS. |
| `WAKE_LOCK` | Передача не останавливается в фоне. |
| `VIBRATE` | Тактильное подтверждение SOS. |
| `RECEIVE_BOOT_COMPLETED` | Возобновить работу после перезагрузки устройства. |

**Мы принципиально НЕ запрашиваем `INTERNET`. BridgeMesh работает только офлайн.**

## 📖 Как работает mesh

```
Вы ──► Аня (50 м, BT) ──► Боря (30 м от Ани, Wi-Fi) ──► Вася
                       ↘
                       Дима ─► Женя
```

1. Вы отправляете сообщение адресату.
2. Телефон ищет ближайших с BridgeMesh. Если адресат виден — отправляет напрямую.
3. Если адресата не видно — отправляет ближайшему соседу с пометкой «для Васи». Тот повторяет.
4. Сообщение хранится у встречных людей до **7 дней**. Когда появляется связь — доставляется.

> Личные сообщения шифруются общим ключом. Ни один посредник не видит текст — только зашифрованный блоб.

## 🔐 Безопасность

| Что | Реализация |
|-----|------------|
| Личные сообщения | AES-256-CBC, ключ из SHA-256 от идентификаторов собеседников |
| Подпись пакетов | HMAC-SHA256 |
| Анти-спам визиток | Подпись + дедуп по `packetId` |
| Бэкап | Пароль → PBKDF2-HMAC-SHA256 → AES |

## 📁 Структура проекта

```
lib/
├── app.dart              # Точка входа, DI-граф сервисов
├── models/               # MeshPacket, Contact, ChatMessage, Conversation

│   ├── message_store     # Store-and-forward
│   ├── secure_chat       # AES + PKCS7
│   ├── backup_service    # Бэкап

│   ├── local_notify.dart # Локальные push-уведомления (без интернета)
│   ├── foreground_service # Держит процесс живым в фоне
│   └── power_mode        # Обычный / эконом-режим
└── ui/
    ├── home_screen.dart  # TabBar
    └── widgets/          # Панели и переиспользуемые компоненты
```
