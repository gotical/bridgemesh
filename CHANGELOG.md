# 1.2.0 — 2025-09-03

### Что нового

- **Личные сообщения шифруются** и собираются в диалоги.
  Каждый диалог 1-на-1, как в обычном мессенджере.
  Внизу — список диалогов с последним сообщением и счётчиком
  непрочитанных.
- **Локальные push-уведомления** работают полностью офлайн
  (через `flutter_local_notifications`). При входящем
  личном сообщении или SOS — уведомление в шторке,
  даже если приложение свернуто и интернета нет.
- **Объявления (broadcast)** — отдельный метод отправки
  сообщения «всем в mesh». Не требует шифрования.
- **Уведомления не путают с общим чатом.** Личные диалоги
  не смешиваются с групповыми городскими чатами.
- **Тон приложения** — утилитарный, без технического жаргона.
  В README нет больше акцента на анонимности или защите
  от кого-либо — это инструмент связи на случай ЧС.

# 1.1.0 — 2025-09-03

### Что нового

- **Сохранение данных** между запусками: имя, телефон, контакты,
  чаты остаются.
- **Фоновая работа** через foreground-сервис — приложение
  не убивается при сворачивании.
- **Режим энергосбережения** — кнопка «Отключиться (эконом)»
  снижает расход заряда в 5-10 раз.
- **Bottom Navigation Bar** выровнен по центру.
- **Исправлены RenderFlex overflow.**

# 1.0.0 — 2025-09-03

Первый публичный релиз.

- Mesh-сеть через Bluetooth LE и Wi-Fi Direct.
- Многошаговая доставка (store-and-forward), до 7 дней.

- Городские геочаты.
- SOS.
