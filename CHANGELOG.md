# 1.1.0 — 2025-09-03

### Что нового

- **Сохранение данных между запусками.** Если вы уже вводили имя и
  телефон — при следующем открытии BridgeMesh сразу открывает чат.
  Приветственный экран показывается только при первом запуске или
  при полной очистке данных приложения.
- **Фоновая работа (foreground service).** Сеть остаётся живой,
  даже если приложение свернуто. В шторке появляется уведомление
  «BridgeMesh работает». Соседям вы видны постоянно.
- **Режим энергосбережения.** Кнопка «Отключиться (эконом)» в
  разделе «Ещё» переводит радио в спящий режим: BLE сканирует раз
  в минуту, Wi-Fi не вещает. Узел остаётся посредником — пропускает
  сообщения через себя. Заряд тратится в 5–10 раз меньше.
- **Новая иконка приложения.** Mesh-схема с буквой «B» (Bridge)
  в центре, неоновая подсветка, надпись «BRIDGE» внизу.
- **Bottom Navigation Bar** выровнен по центру и равномерно
  распределён по ширине экрана.
- **Полностью на русском.** Убраны слова «Node ID», «узел», «mesh»
  из пользовательского интерфейса.
- **Опциональная сверка номера с записной книжкой.** Если собеседник
  ввёл номер у себя — у вас он отображается именем из «Контактов»
  Android (если номер совпадает).

### Исправления

- RenderFlex overflow на странице онбординга (159 px) и на статус-баре
  главного экрана (2.4 px) — контент теперь корректно вписывается
  на маленьких экранах и при появлении клавиатуры.
- Длинные имена/идентификаторы больше не выпирают из карточек
  контактов и чатов — текст обрезается многоточием.

# 1.0.0 — 2025-09-03

Первый публичный релиз BridgeMesh.

- Mesh-сеть через Bluetooth LE и Wi-Fi Direct
- Многошаговая доставка (store-and-forward), до 7 дней
- Сквозное шифрование (AES-256-CBC, ручной PKCS7)
- Идентификатор по hardware fingerprint
- Городские геочаты, SOS, бэкап с паролем
- Полностью на русском
- MIT лицензия, RybinskLab
