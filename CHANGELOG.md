# 1.2.0 — 2025-09-03

### Что нового

- **Личные сообщения шифруются** и собираются в диалоги.
  Каждый диалог 1-на-1, как в обычном мессенджере.
  Внизу — список диалогов с последним сообщением и счётчиком
  непрочитанных.
- **Локальные push-уведомления** работают полностью офлайн
  (через `flutter_local_notifications`). При входящем
  личном сообщении или SOS — уведомление в шторке,
  даже если приложение свернуто и интернета нет.
- **Объявления (broadcast)** — отдельный метод отправки
  сообщения «всем в mesh». Не требует шифрования.
- **Уведомления не путают с общим чатом.** Личные диалоги
  не смешиваются с групповыми городскими чатами.
- **Тон приложения** — утилитарный, без технического жаргона.
  В README нет больше акцента на анонимности или защите
  от кого-либо — это инструмент связи на случай ЧС.

# 1.3.0 — 2025-09-04

### Город

- В шапке теперь показывается ваш **текущий город** сразу,
  как только GPS определит координаты. Если город неизвестен —
  кнопка «Уточнить по GPS» и «Указать вручную».
- Поддерживается **ручной выбор города**: можно написать
  «Ярославль» и попасть в его комнату без GPS.
- Последний определённый город **сохраняется** между запусками.

### Вкладка «Рядом» (новая)

- Отдельный экран со списком людей, которых телефон видит прямо
  сейчас по BLE и Wi-Fi Direct.
- По тапу — быстро добавить в контакты или сразу написать
  личное сообщение. Не надо сканировать QR-коды.

### Городской чат и общий чат (два чата на одной вкладке)

- На вкладке «Город» две подвкладки: **Город** (привязан к
  GPS-городу) и **Общий** (slug `global`, виден всем).
- **Городской** чат меняется автоматически: переехали из
  Рыбинска в Ярославль — попали в чат Ярославля.
- **Общий чат** — единый для всех, история остаётся локально
  и переезжает с телефоном.
- В любом из чатов **тап на сообщение** другого человека открывает
  меню: «Добавить в контакты» или «Написать личное».
- Уведомления приходят в шторку даже когда приложение свернуто
  (через локальный канал `flutter_local_notifications`).

### Прочее

- Локальное push-уведомление теперь приходит и на сообщения
  в чатах (городском и общем).

# 1.3.1 — 2025-09-04

### Доказательство E2E: посредник не видит текст

Личные сообщения и до этого шифровались (AES-256-CBC +
HMAC-SHA256, ключ из SHA-256 от пары alias'ов). В этой версии
добавлено явное доказательство в коде и UI:

- В `MeshPacket.payload` появилось поле `clear: bool`.
  Для личных — `false`, для broadcast — `true`. Это видно
  в коде relay-узла и в логах.
- В `_onIncoming` расшифровка вызывается **только** при
  совпадении `pkt.to == identity.alias`. Посредник не
  вызывает `SecureChat.decrypt` для чужих пакетов.
- `MessageStore` хранит только `MeshPacket` целиком,
  включая **зашифрованный blob** `payload['text']`. Расшифрованный
  текст в хранилище не попадает.
- На странице «Ещё → Ретрансляция в mesh» появился блок
  с пояснением: «Личные сообщения хранятся в зашифрованном
  виде. Этот узел не может прочитать текст».
- Подробный комментарий-документация в `lib/services/secure_chat.dart`.

### Прочее

- В broadcast-пакетах (`sendBroadcast`) тоже проставлен флаг
  `clear: true` для согласованности.

# 1.4.0 — 2025-09-04

### 📷 Сканирование QR-кодов через камеру

- Новая зависимость `mobile_scanner: ^4.0.0` (CameraX + MLKit).
- Новый экран `QrScannerScreen` — открывает камеру, считывает
  QR, возвращает строку. Особенности:
  - Затемнение по краям с подсветкой рамки для наведения.
  - Иконка фонарика в углу — нажатие включает подсветку.
  - Кнопка «Назад» — выход без сканирования.
  - Обработка ошибок: «Нет разрешения на камеру», «Камера
    не поддерживается» и т.п.
- В карточке «Моя визитка» добавлена кнопка **«Сканировать»**
  (зелёная, выделена как основное действие) — открывает
  сканер.
- При считывании распознаётся `bridgemesh://contact?id=...&alias=...`
  и контакт автоматически добавляется с правильным именем.
- В `PermissionService` добавлен `ensureCamera()` — запрашивает
  разрешение на камеру перед сканированием.

### Прочее

- `ContactService.addContact` теперь принимает `alias` —
  имя сохраняется сразу при добавлении (раньше надо было
  потом редактировать).
- В `_enterContactCode` имя из поля «Имя» теперь сохраняется
  в контакт.
- В `_handleDeepLink` (QR/share) тоже используется `alias`
  из URL.
